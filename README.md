# 👑 O Império Kardashian-Jenner — Website Informativo

Este projeto é uma aplicação web interativa e elegante dedicada a explorar a trajetória, os negócios multimilionários e o impacto cultural de uma das famílias mais influentes do século XXI: o clã Kardashian-Jenner. 

O site combina uma estética de luxo minimalista com elementos dinâmicos para oferecer uma experiência imersiva e responsiva aos usuários.

---

## 🎯 Objetivo do Projeto
O principal objetivo deste projeto é consolidar conhecimentos práticos de desenvolvimento front-end moderno (HTML5, CSS3 estruturado e JavaScript vanilla). A proposta foi criar uma interface limpa, de alta fidelidade visual, simulando um portal premium de entretenimento e negócios que apresente de forma clara a biografia e as marcas fundadas por cada integrante da família.

---

## 🛠️ Tecnologias Utilizadas
O projeto foi desenvolvido utilizando tecnologias web nativas, sem a necessidade de frameworks externos, priorizando a performance e a semântica:

* **HTML5:** Estruturação semântica do conteúdo (`<header>`, `<main>`, `<section>`, `<article>`, `<iframe>`).
* **CSS3:** Estilização baseada em uma paleta de cores neutras e sofisticadas. Utilização de **CSS Grid** e **Flexbox** para layout fluido e responsivo, além de transições dinâmicas (*hover effects*).
* **JavaScript (ES6+):** Inserção de interatividade, manipulação do DOM e controle de mídia/responsividade dos elementos dinâmicos.

---

## 🚀 Funcionalidades
* **Painel de Apresentação Dinâmico:** Grade informativa com cartões (*cards*) interativos dedicados a cada integrante (Kris, Kim, Kourtney, Khloé, Kendall e Kylie).
* **Mídia Incorporada e Responsiva:** Integração avançada com a API de players de vídeo do YouTube (Trailer Oficial/Conteúdo de Destaque), configurado com técnicas de CSS para se redimensionar mantendo a proporção de 16:9.
* **Efeitos Visuais Premium:** Animações sutis de elevação e sombreamento ao interagir com as informações das empresárias.
* **Design Totalmente Responsivo:** Adaptação fluida e otimizada para desktops, tablets e smartphones.
